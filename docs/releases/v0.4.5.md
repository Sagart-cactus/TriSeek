# TriSeek v0.4.5

v0.4.5 is a macOS installer and release packaging update for browser-downloaded archives.

## Highlights

- `scripts/install.sh` now clears `com.apple.quarantine` and `com.apple.provenance` from both installed binaries after copying them into the install directory.
- The installer re-applies an ad-hoc signature on macOS binaries after removing those extended attributes.
- macOS release jobs explicitly ad-hoc sign both `triseek` and `triseek-server` before packaging.
- The install guide documents the same manual recovery commands for users who download and unpack macOS release archives without using the installer.

## Root Cause

The released Apple Silicon binary was already linker-signed ad-hoc, which the kernel accepts. Browser downloads can still attach `com.apple.quarantine` to the extracted binaries, and Apple Silicon Gatekeeper may SIGKILL an ad-hoc-signed quarantined binary before it can start.

## Fix Details

- `scripts/install.sh` removes quarantine and provenance attributes from `triseek` and `triseek-server` after installation.
- On macOS, the installer runs `codesign --force --sign -` on both binaries after the attributes are removed.
- `.github/workflows/release.yml` signs both macOS binaries before creating release archives.
- `docs/install.md` and `docs/install.html` now document the manual `xattr` and `codesign` steps.

## Migration Notes

No migration is required for users who install with `scripts/install.sh`. Re-run the installer to refresh both binaries:

```sh
curl -fsSL https://raw.githubusercontent.com/Sagart-cactus/TriSeek/main/scripts/install.sh | sh
```

If you manually downloaded a macOS tarball through a browser, clear the attributes and re-sign both binaries:

```sh
xattr -dr com.apple.quarantine ~/.local/bin/triseek ~/.local/bin/triseek-server
xattr -dr com.apple.provenance ~/.local/bin/triseek ~/.local/bin/triseek-server
codesign --force --sign - ~/.local/bin/triseek
codesign --force --sign - ~/.local/bin/triseek-server
```
