# TriSeek v0.5.7

v0.5.7 is a usage metrics stability release.

## Highlights

- Usage metrics writes now build a complete JSONL line before appending it to disk.
- Usage metrics reads now tolerate adjacent JSON event objects on the same line, which lets local reports recover from previously concatenated event writes.
- Added regression coverage for reading concatenated usage metrics events.

## Migration Notes

No configuration changes are required.

## Validation

- `cargo fmt`
- `cargo test -p search-core usage_metrics_reader_accepts_concatenated_jsonl_events`
- `cargo test --workspace --locked`
